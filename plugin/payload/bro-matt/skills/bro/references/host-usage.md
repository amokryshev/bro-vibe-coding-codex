# Host-вызовы

Bro + Matt Pack — один набор проектных навыков для Codex и Claude Code. Содержимое навыков общее. Установщик размещает его в штатном каталоге skills соответствующего host при настройке проекта; системная установка не означает, что этот проект настроен.

## Найти навык

Используй название из текущего списка навыков host и фактический путь к его `SKILL.md`. Соседние навыки из этого набора лежат рядом с каталогом `bro`. Запись `/tdd` в документах Matt означает навык `tdd`; синтаксис вызова определяется текущим host. В Codex пользователь обычно указывает `$tdd`, в Claude Code — `/tdd`. Наличие служебного инструмента с именем `Skill` не предполагается универсальным: используй его, когда он доступен; иначе читай указанный файл как инструкцию workflow. Соблюдай ограничения явного/неявного вызова и поручение пользователя.

`disable-model-invocation: true` сохраняется у upstream-навыков. Прямой вызов пользователя и применение инструкции внутри согласованного маршрута должны оставаться различимыми: не заявляй, что host вызвал skill, если только прочитал файл.

## Выполнить действие

Трекер, структура документов и команды проекта задаются его соглашениями. Для Jira может быть доступен Atlassian MCP, для GitHub — `gh`, для локального трекера — файлы; способ выбирается по фактическим соглашениям и доступу. Bro не устанавливает другие инструменты и не требует конкретного поставщика интеграции.

Подагенту передавай достаточный контекст и проверяй результат. Названия инструментов делегирования отличаются; используй реально доступные. Отсутствие независимого контекста сообщай как ограничение проверки.

Разрешения, доверие проекту и OAuth принадлежат host. Отказ разрешения не обходится альтернативным инструментом. Прочитанный manifest, найденный файл или запущенная команда не заменяют подтверждение реальной операции.
